<ss-player-webgpu> — Web Component

1 要素 = 1 canvas = 1 体。マークアップに置くだけで再生が始まります。内部ではページ共有の SsContextWeb（device・パイプライン・アトラス）から surface を 1 枚もらっているだけなので、この要素を 10 個置いても GPUDevice は 1 つです（それを実測しているのが 1 ページに複数）。

play() は頭出しです。pause() の続きから再生するのは resume() のほう。

画面外・バックグラウンドで rAF を止めます（既定 on）。切り替えは属性を書き換えるだけ。

いま画面に置かれているもの

パネルの操作を反映した、そのままコピーできるマークアップです。



  
属性を書き換えるとそのまま反映されます

  
src・pack・animation・speed-scale・fit・align・flip-x・flip-y は、置いた後に書き換えても効きます。上のパネルはどれも setAttribute を 1 行呼んでいるだけです。src を変えたときは、読み込みが済むと load イベントが届きます。

  
el.setAttribute('src', 'assets/Mesh.ssab');
el.addEventListener('load', () => console.log(el.player.animationNames()));
el.setAttribute('animation', 'walk');   // autoplay があれば頭から再生

  
スクリプトから切り替えるなら element.loadSrc(src, pack?, animation?, read?) もあります。戻り値はアニメーション名の配列で、連続で呼んでも要素側で直列化され、最後に呼んだものが画面に残ります。


  
イベント

  
再生が起こしたことは DOM イベントとして届きます。animationstarted・animationfinished・animationlooped と、タイムラインの userdata・signal・audio（中身は event.detail）です。上の「イベント」の行は、この 6 つを表示しています。

  
el.addEventListener('animationfinished', () => showNextButton());
el.addEventListener('userdata', (e) => console.log(e.detail.text));


  
プレイヤー API にはここから届きます

  
el.player    // SsPlayerWeb — トランスポート、パーツ上書き、events()
el.surface   // SsSurfaceWeb — stats()、resize()
el.ctx       // SsContextWeb — ページ共有の device


  
WebGPU 対応ブラウザ（Chrome / Edge 113+、Safari 26+、Firefox 141+）と
     http://localhost 配信が必要です。
