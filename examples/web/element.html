<ss-player-webgpu> — Web Component

1 要素 = 1 canvas = 1 体。マークアップに置くだけで再生が始まります。 内部ではページ共有の SsContextWeb（device・パイプライン・アトラス）から surface を 1 枚もらっているだけなので、この要素を 10 個置いても GPUDevice は 1 つです （それを実測しているのが 1 ページに複数）。

…

play() は頭出しです。pause() の続きから 再生するのは resume() のほう。

画面外・バックグラウンドで rAF を止めます（既定 on）。 切り替えは属性を書き換えるだけ。

いま画面に置かれているもの

パネルの操作を反映した、そのままコピーできるマークアップです。



  
属性を書き換えても再ロードはされません

  
src は初回接続のときだけ読まれます。実行時にパックを差し替えるのは
     element.loadSrc(src, pack?, anim?) で、戻り値はアニメーション名の配列です。
     上の ssab セレクトがやっているのはこれ 1 行です。

  
const names = await el.loadSrc('assets/overall/Mesh.ssab');
el.player.setAnimation(names[0]);   // loadSrc が済ませているので通常は不要

  
連続で呼んでも安全です — 要素側で直列化していて、最後に呼んだものが画面に残ります。
     プレイヤー本体はロード中コンテキストから外れるので、SsPlayerWeb を直接使う場合は
     await してください（2 本同時に走らせると reject されます）。


  
プレイヤー API にはここから届きます

  
el.player    // SsPlayerWeb — トランスポート、パーツ上書き、events()
el.surface   // SsSurfaceWeb — stats()、resize()
el.ctx       // SsContextWeb — ページ共有の device


  
WebGPU 対応ブラウザ（Chrome / Edge 113+、Safari 26+、Firefox 141+）と
     http://localhost 配信が必要です。
